# Rencana: Adaptasi Section Lines & Dynamic Title dari Odoo

## Status Saat Ini

**Status PO yang ada:** draft, dikirim, disetujui, diterima_sebagian, diterima, dibatalkan

**Struktur item:** `purchase_order_items` hanya memiliki item produk biasa (barang_id required). Tidak ada `display_type` atau field untuk section/note lines.

**Judul PDF:** Fixed dari settings (`judul_laporan`), tidak berubah berdasarkan status.

---

## Fitur 1: Dynamic Title

Judul PDF berubah otomatis berdasarkan status PO, mirip Odoo (RFQ/PO/Cancelled).

### Mapping Title

| Status | Judul PDF |
|--------|-----------|
| draft | Pengajuan Pembelian |
| dikirim | Pengajuan Pembelian |
| disetujui | Purchase Order |
| diterima_sebagian | Purchase Order |
| diterima | Purchase Order |
| dibatalkan | Pembelian Dibatalkan |

### File yang Diubah

**1. `resources/views/pdf/purchase-order.blade.php` (line 140)**
```blade
{{-- Sebelumnya --}}
<div class="doc-title">{{ $setting['judul_laporan'] ?? 'PURCHASE ORDER' }}</div>

{{-- Sesudahnya --}}
@php
  $statusTitles = [
    'draft' => 'Pengajuan Pembelian',
    'dikirim' => 'Pengajuan Pembelian',
    'disetujui' => 'Purchase Order',
    'diterima_sebagian' => 'Purchase Order',
    'diterima' => 'Purchase Order',
    'dibatalkan' => 'Pembelian Dibatalkan',
  ];
  $docTitle = $statusTitles[$po->status] ?? ($setting['judul_laporan'] ?? 'PURCHASE ORDER');
@endphp
<div class="doc-title">{{ $docTitle }}</div>
```

## Fitur 2: Section Lines

Memungkinkan item PO dikelompokkan dalam section dengan subtotal per section, mirip Odoo.

### Perubahan Database

**Migration baru: `add_display_type_to_purchase_order_items_table.php`**
- Tambah kolom `display_type` (nullable string): `section`, `note`, atau `null` (item biasa)
- Tambah kolom `urutan` (integer, default 0): untuk urutan tampil
- Kolom `barang_id` diubah ke nullable (section/note tidak perlu barang)
- Kolom `jumlah`, `harga_satuan`, `diskon`, `subtotal`, `nilai_pajak`, `total_setelah_pajak` tetap nullable untuk section/note

### File yang Diubah

**1. Migration: `database/migrations/xxxx_add_display_type_to_purchase_order_items_table.php`**
```php
Schema::table('purchase_order_items', function (Blueprint $table) {
    $table->string('display_type')->nullable()->after('purchase_order_id');
    $table->integer('urutan')->default(0)->after('display_type');
    $table->foreignUuid('barang_id')->nullable()->change();
});
```

**2. Model: `app/Models/PurchaseOrderItem.php`**
- Tambah `display_type` dan `urutan` ke `$fillable`
- Tambah method `isSection()`, `isNote()`, `isProduct()`
- Tambah scope `ordered()` untuk sort by urutan

**3. Controller: `app/Http/Controllers/PurchaseOrderItemController.php`**
- Update validation: `barang_id` nullable jika `display_type` section/note
- Tambah endpoint `storeSection()` atau handle via store dengan display_type
- Update `index()` untuk sort by urutan

**4. Service: `app/Services/PurchaseOrderService.php`**
- Update `recalculate()` untuk handle section subtotal

**5. Blade Template: `resources/views/pdf/purchase-order.blade.php`**
```blade
@php $no = 1; $currentSection = null; $sectionSubtotal = 0; @endphp
@foreach ($po->items->sortBy('urutan') as $item)
  @if ($item->display_type === 'section')
    {{-- Tutup section sebelumnya --}}
    @if ($currentSection)
      <tr class="section-subtotal">
        <td colspan="6" class="right">Subtotal</td>
        <td class="total-col">{{ number_format($sectionSubtotal, 0) }}</td>
      </tr>
    @endif
    {{-- Header section baru --}}
    <tr class="section-row">
      <td colspan="7" class="section-title">{{ $item->keterangan }}</td>
    </tr>
    @php $currentSection = $item; $sectionSubtotal = 0; @endphp

  @elseif ($item->display_type === 'note')
    <tr class="note-row">
      <td colspan="7" class="note-text">{{ $item->keterangan }}</td>
    </tr>

  @else
    {{-- Item produk biasa --}}
    <tr>
      <td class="no-col">{{ $no++ }}</td>
      <td class="product-col">{{ $item->barang->nama ?? '-' }}</td>
      <td class="qty-col">{{ number_format($item->jumlah, 0) }}</td>
      <td class="price-col">{{ number_format($item->harga_satuan, 0) }}</td>
      <td class="disc-col">{{ $item->diskon > 0 ? number_format($item->diskon, 0) : '0' }}</td>
      <td class="tax-col">{{ $item->nilai_pajak > 0 ? number_format($item->nilai_pajak, 0) : '0' }}</td>
      <td class="total-col">{{ number_format($item->total_setelah_pajak, 0) }}</td>
    </tr>
    @php $sectionSubtotal += $item->total_setelah_pajak; @endphp
  @endif
@endforeach
{{-- Tutup section terakhir --}}
@if ($currentSection)
  <tr class="section-subtotal">
    <td colspan="6" class="right">Subtotal</td>
    <td class="total-col">{{ number_format($sectionSubtotal, 0) }}</td>
  </tr>
@endif
```
