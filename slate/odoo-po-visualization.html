report_purchaseorder_document

Struktur Template Odoo QWeb

  • t-call Memanggil template lain (web.external_layout)
  • t-set Menyimpan variabel (o, address, layout_document_title)
  • t-field Menampilkan field dari model (o.partner_id, o.name)
  • t-if Kondisional (cek state draft/purchase/cancel)
  • t-foreach Loop item order_line
  • t-options Opsi formatting (monetary, date_only, widget)

Referensi Struktur Template

<template id="report_purchaseorder_document">
    <t t-call="web.external_layout">           ← Layout utama Odoo
        <t t-set="o" t-value="o.with_context(...)"/  ← Set bahasa
        <t t-set="address">...</t>                ← Alamat vendor
        <t t-if="o.dest_address_id">...</t>      ← Alamat pengiriman (opsional)

        <div class="page">
            <t t-set="layout_document_title">      ← Judul dinamis
                t-if="o.state in ['draft','sent','to approve']" → RFQ
                t-if="o.state == 'purchase'" → Purchase Order
                t-if="o.state == 'cancel'" → Cancelled
            </t>

            <table class="o_main_table">            ← Tabel item
                t-foreach="filtered_lines" t-as="line"  ← Loop order line
                    t-if="not line.display_type"         ← Produk biasa
                    t-if="line.display_type == 'line_section'" ← Section header
                    t-if="line.display_type == 'line_note'"    ← Catatan
            </table>

            <div id="total">                          ← Total pajak
                t-call="purchase.document_tax_totals"
            </div>

            <p t-field="o.note"/>                   ← Catatan PO
            <span t-field="o.payment_term_id"/>       ← Syarat bayar
        </div>
    </t>
</template>
