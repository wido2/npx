Analisis Perbedaan & Rekomendasi
Aspek Odoo Template Laravel Template Gap
Rendering Engine QWeb (XML-based, Python backend) Blade (PHP-based, DomPDF) △
Layout System Inherits dari web.external_layout (header/footer otomatis) Self-contained, semua styling inline △
Dynamic Title Berubah sesuai state: RFQ / PO / Cancelled Fixed "PURCHASE ORDER" dari settings ✗
Line Types Produk, Section, Subsection, Note Hanya produk biasa ✗
Subtotal per Section Otomatis dihitung per section Tidak ada ✗
Multi-UOM Tampilkan konversi UOM jika berbeda Hanya tampilkan jumlah ✗
Tax Display Grouped tax totals (dari account module) Simple: Total Pajak saja △
Signature Box Tidak ada 4 box: Dibuat/Mengetahui/Menyetujui/Penerima ✓ Laravel unggul
Terbilang Tidak ada Ada (terbilang function) ✓ Laravel unggul
Customization UI Via Odoo Studio atau code Settings form (warna, font, logo, toggle) ✓ Laravel unggul
Portal Integration Ada "Connect your software" link Tidak ada ✗
Kesimpulan: Template Odoo lebih fleksibel untuk multi-line types dan integrasi ERP, tetapi template Laravel sudah memiliki fitur yang lebih relevan untuk dokumen PO Indonesia (tanda tangan, terbilang, NPWP, customisasi via UI). Untuk meniru struktur Odoo, perlu ditambahkan: dynamic title berdasarkan state, section/subsection lines, per-section subtotal, dan multi-UOM display.
